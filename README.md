# Campus-Compass
Real-time faculty availability and location tracking system for VJEC using biometric logic and interactive 3D mapping.

Campus Compass 🧭

Problem: Students often waste time searching for faculty members across large campuses, not knowing if they are in class, in their cabin, or on leave.

Solution: Campus Compass is a web-based dashboard that predicts faculty location in real-time. It does not use invasive GPS tracking. Instead, it utilizes a "Logic Algorithm" that cross-references Biometric Attendance Data with Static Academic Timetables.

Features:

Interactive 3D Map: A CSS-based isometric map of VJEC (Main Block, CS, Mech, etc.).

Privacy Focused: Calculates location based on schedule logic, not physical sensors.

Instant Search: Locate any faculty member by name or department instantly.

Tech Stack: HTML5, CSS3 (Advanced 3D Transforms), Vanilla JavaScript.
